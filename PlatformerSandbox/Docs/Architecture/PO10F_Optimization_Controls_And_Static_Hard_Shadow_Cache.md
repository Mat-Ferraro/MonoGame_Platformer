## UI contract
* First row of BOTH Lighting Quality Lab and Engine Performance Lab: **ENABLE ALL OPTIMIZATIONS**, status `ALL 14 ON` or `ENABLE`. Enables seven original flags (127), five PO10A flags (31), shadow-free static field reuse, and the experimental static hard-shadow field reuse. A matching **DISABLE ALL LIVE OPTIMIZATIONS** action supports comparisons. Both clear renderer caches at the existing profile-change boundary, cancel active manual captures, and reset timing history.
* Resolution, area samples/adaptive policy, bloom scale, shadow softness, art, motion, quality, FPS cap, VSync, and fixture are preserved. Select an explicit quality preset if desired. No implicit quality reduction.
* Process-only switches are normally on, but cannot be hot-switched. Summary on first page and individual read-only statuses later; if disabled by an environment override, restart with candidate/default process flags. This includes the new caster scratch-buffer switch. Lab action does not modify saved preferences.
* Graphics Settings: **ENABLE ALL ESTABLISHED OPTS**, then **APPLY AND SAVE**. Enables mask 127, PO10A mask 31, and previously tested shadow-free static caching without modifying the saved resolution/quality controls. Static hard-shadow cache is an explicitly experimental separate toggle. It requires static field caching; disabling the parent in a lab disables the child. Old graphics.json remains supported via optional fields and unchanged version.

## Hard-shadow static field experiment
`PS_PO_10F_STATIC_SHADOWS=1` plus `PS_PO_10B_STATIC_FIELDS=1` enables the candidate path during process-configured tests. Disabled by default. Labs can explicitly select it, and enable-all includes it. Saved graphics can explicitly opt in.

Eligible only for exact stationary viewport, hard-shadow receiving layer with point lights, no explicit routing-list objects, at most 64 lights and 128 blockers, nonempty blocker list and at least one quota-eligible shadow-casting light illuminating the layer. Cache key compares ordered light values, current shadow quota bitmap, ambient, layer properties, budget, sampling, art light multiplier/radius/posterization, exact viewport and complete ordered blocker identity, owner, layer, face metadata, depth and vertex values. Snapshot has defensive vertex copies; edited arrays must not match the prior key. Soft shadows, area/directional/spot lights, unsupported routing and larger inputs remain on existing paths. Target recreation and device/scene invalidation retain existing cache reset paths. Existing three-field/16 MiB additional field target budget unchanged. This is field reuse, NOT light-relative GPU texture reuse during a moving camera.

A hard-shadow field hit counts reuse of an eligible field; it does not guarantee each constituent light has a nearby visible caster. Compare reference mask workload and images as well as hit counter. Snapshot copies may add allocation overhead; measure before accepting this experiment. Do not promote it as a default until it is exercised and visually validated.

## Caster list allocation
`PS_PO_10F_CASTER_BUFFERS=0` restores the original per-light list allocation. The default reuses two renderer-owned lists in synchronous layer shadow preparation only. `FilterInto` preserves validation, order, inclusive margin, and output; rejects aliased input/output. Layer visibility caches take their own copies of inputs as needed. Production material paths retain original lists because the hard mask key can retain a reference for the remainder of the frame. Scratch lists are cleared at end of layered frame.

## Test workflow
1. `dotnet test .\PlatformerSandbox.Tests\PlatformerSandbox.Tests.csproj -c Release`
2. `py .\Tools\po_run_benchmarks.py --po10f --tier quick` (5 cases: stationary reference/cached, buffers off, moving reference/cached; 60 minimum warmup, 120 recorded, adaptive for stationary). `--tier standard` includes both soft-shadow guard cases. No need for full sweep during development.
3. `py .\Tools\po_visual_regression.py --hard-cache --no-build` (10 captures across stationary hard, moving hard, and soft guard; repeat reference controls; strict RGB equivalence). An unexercised stationary hard cache is inconclusive, not a pass. A soft hard-cache hit is rejected. Visual captures at discrete positions do not prove temporal stability.
4. Manual: select Lighting Quality Lab. Choose desired quality profile; note scales, sample count, bloom and VSync. Press Enable All. Verify all live flags on and quality settings unchanged. Disable All and compare; re-enable. Select `static_shadow` fixture, freeze motion and let camera settle; check `STATIC HARD FIELD HITS`; move and inspect shadow correctness. Toggle soft shadows and verify hard hits stop. Repeat controls in Performance Lab. Set Graphics Settings enable-all, Apply and Save, restart and verify persistent settings. Ensure lab settings do not leak into gameplay.
5. Upload benchmark and visual ZIPs. The missing source is still required for the shader work: `py .\Tools\po_export_source.py`. Review archive before upload. In particular include actual `.fx` and any includes, `.mgcb`, `.csproj`, props/targets.

## Remaining PO10F
Light-relative regional GPU mask textures, camera-independent shader sampling, fused material passes, single-channel renderable formats (backend capability/clear/blend/sampling tests), broader static field support, material allocation reduction, final preset acceptance and scalability still pending. No claims of measured speedup, C# compilation or visual correctness in this candidate. 18 Python unit tests passed; C# tests prepared. No large GPU changes are attempted without shader source. Existing reference settings remain available.
